던전 탐험 앱 설치 방법

[1] GitHub에 올리기 (윈도우 컴퓨터)
1. github.com 에서 회원가입
2. 오른쪽 위 + 버튼 → New repository
   - Repository name: dungeon (원하는 영어 이름)
   - Public 선택 → Create repository
3. 만들어진 페이지에서 "uploading an existing file" 클릭
4. 이 zip을 푼 폴더 안의 파일을 전부 끌어다 놓기 (폴더째가 아니라 안의 파일들)
5. 아래 Commit changes 클릭
6. 위쪽 Settings → 왼쪽 Pages
   - Branch: main, 폴더: / (root) → Save
7. 1~2분 뒤 같은 화면 위쪽에 주소가 생김
   예: https://내아이디.github.io/dungeon/

[2] 아이폰에 설치
1. 사파리로 위 주소 열기 (크롬 말고 사파리)
2. 아래 공유 버튼 → 홈 화면에 추가 → 추가
3. 홈 화면의 던전 탐험 아이콘으로 실행

[3] 진행 상황 옮기기
1. Claude 버전 로비 → 저장 옮기기 → 코드 복사하기
2. 앱 로비 → 저장 옮기기 → 붙여넣기 → 불러오기 두 번 누르기

[4] 업데이트할 때
새 index.html을 GitHub 저장소에 같은 방법으로 다시 올리면 돼요.
앱을 한 번 껐다 켜면 새 버전이 적용돼요.
